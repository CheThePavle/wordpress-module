# Сайт Государственного театра кукол Удмуртской Республики

Разработка сайта Государственного театра кукол на базе CMS **WordPress** с использованием готового HTML-шаблона, HTML5, CSS3 и JavaScript.

## Основной функционал
- Главная страница с информацией о театре, слайдером, премьерами, контактами и формой записи в театральную студию.
- Каталог спектаклей с фильтрацией по категориям и пагинацией.
- Отдельные страницы спектаклей с подробной информацией и фотографиями.
- Разделы услуг, проектов и новостей.
- Возможность управления содержимым сайта через административную панель WordPress без редактирования кода.
- Интеграция сторонних плагинов для слайдера и социальных сетей.

## Разработка собственных плагинов
- **Float Menu** — плавающее навигационное меню, подключаемое с помощью шорткода.
- **expoPDF** — генерация PDF-документа с информацией о спектакле, фотографией и повторяющимся водяным знаком с названием спектакля.

## Технологии
WordPress, PHP, HTML5, CSS3, JavaScript, плагины WordPress, графический дизайн, PDF.

Описание проекта можно найти в папке "Документы/Модуль D"
